# 环境变量清单

与仓库根目录 `.env.example` 对齐。真实值只写在本地 `.env`，**永不 commit**。

| 变量名 | 必填 | 默认（示例） | 说明 | 示例（假值） |
|--------|------|--------------|------|--------------|
| `MYSQL_ROOT_PASSWORD` | 是 | （无安全默认） | MySQL root 密码 | `change_me_root` |
| `MYSQL_DATABASE` | 是 | `qc_platform` | 业务库名 | `qc_platform` |
| `MYSQL_USER` | 是 | `qc_user` | 应用账号 | `qc_user` |
| `MYSQL_PASSWORD` | 是 | （无安全默认） | 应用账号密码 | `change_me_user` |
| `MYSQL_HOST` | 是 | `db` | 容器网络内主机名；本机连映射端口时用 `127.0.0.1` | `db` |
| `MYSQL_PORT` | 否 | `3306` | 主机映射与客户端端口 | `3306` |
| `DATABASE_URL` | 是 | 见 example | SQLAlchemy URL（`mysql+pymysql://...`） | `mysql+pymysql://qc_user:change_me_user@db:3306/qc_platform` |
| `APP_HOST` | 否 | `0.0.0.0` | API 监听地址 | `0.0.0.0` |
| `APP_PORT` | 否 | `8000` | API 端口（主机映射） | `8000` |
| `LOG_LEVEL` | 否 | `INFO` | 日志级别 | `INFO` |
| `RULES_VERSION` | 否 | `v1` | 规则集版本占位；**待后端接入**后生效 | `v1` |

修改后通常需要：

```bash
docker compose up -d --force-recreate
```

注意：已初始化的 MySQL volume **不会**因改 `MYSQL_*` 密码环境变量而自动改库内账号；改密需 DBA 操作或重建 volume（会丢数据）。
