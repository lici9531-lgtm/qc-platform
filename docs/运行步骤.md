# 运行步骤（一页纸）

日常命令均在仓库根目录 `qc-platform/` 执行。先有 `.env`（`cp .env.example .env`）。

## 启停

```bash
docker compose up --build -d   # 构建并后台启动
docker compose up -d           # 已构建过则直接启
docker compose down            # 停止并移除容器；保留 volume（数据不丢）
docker compose down -v         # 慎用：连同 volume 删除
```

## 状态与日志

```bash
docker compose ps
docker compose logs -f
docker compose logs -f api
docker compose logs -f db
docker compose logs --tail=100 api
```

## 重建

```bash
docker compose build --no-cache api
docker compose up -d --force-recreate api
```

## Volume

```bash
docker volume ls | grep qc-platform
# 命名 volume：qc-platform-mysql-data
docker volume inspect qc-platform-mysql-data
```

## 备份提醒

- 重要变更或演练前备份 MySQL volume 或 `mysqldump`（备份文件勿提交；`*.sql.gz` 已在 `.gitignore`）。
- 恢复前先 `docker compose down`，确认目标环境无误再覆盖。

## 探活（stub）

```bash
curl -s http://127.0.0.1:${APP_PORT:-8000}/
```

业务 API **待后端接入** 后再用 `/datasets`、`/runs` 等做 smoke。
