# 已知限制（v1 / 运维视角）

- **无前端**：仅 API + Compose；浏览器 UI 不在范围。
- **无 Celery / Redis / 自动重试队列**：单 worker **同步**执行。
- **无自动重跑**：中断或失败的 run 标 `failed`（中断为 `error=interrupted`），需人工再提交新 run。
- **无 K8s / 微服务**：单 compose 骨架（`db` + `api`）。
- **Stub 阶段**：当前 API 镜像为占位 HTTP 服务；业务路由、状态机、规则引擎 **待后端接入** 后替换 Dockerfile CMD 与探活。
- **密钥与 venv 永不入库**：只提交 `.env.example`；真实 `.env`、虚拟环境、uploads、备份包不进 Git。
- **产品口径一句**：低置信度 ≠ 错标（细节见产品/规则文档，运维不展开）。
- **E2 相关**：干净目录 clone + `docker compose up` 一次成功、重启数据不丢、kill -9 恢复日志证据——业务证据部分依赖后端落地。
