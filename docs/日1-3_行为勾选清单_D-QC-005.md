## 日2｜issues 必含字段 + `type` 枚举

**范围：** 每条 issue 行为上具备：`row_index`、`column`、`type`、`value`，以及 D-QC-005 的 `sample_id`；`type` 只允许契约现行枚举（含 `duplicate_sample_id` 等已冻结四类/扩展表——以契约短名为准，勿自造别名）。

### 正常路径
- [ ] D2-N1（仅新形状）构造至少 1 条确认类问题（如非法 label）：issue 含现行短名四件套 + `sample_id`；`row_index` 为 0-based（契约现行）
- [ ] D2-N2 `summary` 计数与 `issues` 长度/分类一致（计数键名跟契约现行短名）
- [ ] D2-N3 同输入双跑：`issues` 顺序稳定（或按契约排序键排序后一致）

### 异常路径（≥1）
- [ ] D2-E1 重复 `sample_id`：出现 `type=duplicate_sample_id`（或契约现行等价枚举值）；**禁止**静默改写 id
- [ ] D2-E2 空 `sample_id`：正式禁止 + **显式 issue**；**禁止**静默 `row{n}`（D-QC-005 §9）

### 明确不测（本日）
- 不测 `verdict=suspected|confirmed`（日5）
- 不测 confidence 数值校验（E2 前 Won’t）

**通过条件：** D2-N1 + D2-N3 +（D2-E1 或 D2-E2）勾选；未跑通不算。
